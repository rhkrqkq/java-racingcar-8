# java-racingcar-precourse

## 구현할 기능 목록
### 입력
- 자동차 이름
  - 자동차 이름을 쉼표(,) 기준으로 입력받기
- 시도 횟수 입력받기

### 자동차
- 객체 생성
- 전진 함수
    - 0~9 사이의 무작위 값 생성
    - 무작위 값이 4 이상일 경우 전진, 3 이하일 경우 정지

### 경주
- 자동차 이름을 리스트로 변환
- 예외 처리
  - 자동차 이름이 0자 혹은 5자를 초과
  - 자동차 이름이 중복될 경우
  - 자동차가 1대 이하인 경우
  - 시도 횟수가 정수가 아닌 경우
- 자동차 전진
- 우승자 선정 함수

### 출력
- 차수별 실행 결과 출력
- 우승자 안내 문구 출력
  - 단독 우승자일 시 그대로 출력
  - 우승자가 여러 명일 경우 쉼표(,) 로 구분하여 출력
